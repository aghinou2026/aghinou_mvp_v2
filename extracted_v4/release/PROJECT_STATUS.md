# Aghinou — Production Ready v4

این بسته بر پایه `Aghinou_RELEASE_CANDIDATE` ساخته شده است.

## اصلاحات انجام‌شده در کد
- جستجوی واقعی محلی روی آگهی‌های دریافت‌شده.
- فیلتر دسته‌بندی.
- بررسی اشتراک فعال قبل از نمایش فرم ثبت آگهی.
- ثبت آگهی از طریق RPC سمت سرور به جای insert مستقیم.
- اعمال سقف ۹ آگهی و نیاز به اشتراک فعال در سمت سرور.
- جلوگیری از درج مستقیم payment توسط کاربر در migration امنیتی.
- نمایش وضعیت اشتراک در حساب کاربری.

## وضعیت اجرای واقعی
1. Migration امنیتی و جدول payments روی پروژه واقعی Supabase اجرا و بررسی شد.
2. RLS و Storage Policies اصلی بررسی و اصلاح شد.
3. ورود با OTP ایمیلی در کد نسخه فعال است و به تنظیم Email OTP در Supabase نیاز دارد.
4. پرداخت و callback هنوز به تست تراکنش واقعی نیاز دارد.
5. اجرای ابزارهای Flutter و ساخت Release.
6. Deploy Web و تست اینماد روی `aghinou.ir`.

این بسته APK تست‌شده محسوب نمی‌شود تا build واقعی روی محیط Flutter انجام شود.
